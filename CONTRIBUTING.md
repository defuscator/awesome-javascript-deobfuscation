# Contributing

Additions and corrections are welcome, including entries for tools that compete with Defuscator.

An entry should:

- **Be about JavaScript deobfuscation, unpacking, or the tooling around it.** General JavaScript
  tools belong in other lists.
- **Say plainly whether the tool executes the code it analyses**, and carry ⚠️ if it does. This is
  the single most useful fact for someone about to feed it live malware.
- **Link to the project itself**, not a blog post about it, unless it is in the Techniques section.
- **Use a short, factual description.** No "best", "most powerful" or star counts; they go stale.
- **Note if the project is archived or unmaintained.**

Keep one entry per line in the format:

```
- [Name](link) - Description.
```

Open a pull request, or an issue if you are not sure where something belongs.
